# Dialogue Design Document

## 1. Overview

This document defines every voice dialogue used by Voice Guide AI throughout the Kisan Unnati platform.

Every dialogue should be:

- Simple
- Farmer-friendly
- Short
- Easy to understand
- Multilingual
- Offline compatible

Dialogues should never replace Pragati AI.

Voice Guide only explains the application.

# 17. Dialogue Rules

Every dialogue must follow these rules:

- Speak naturally.
- Maximum duration should normally be under 20 seconds.
- Avoid technical terms.
- Use simple farmer-friendly language.
- Never interrupt user interaction.
- Always support subtitles.
- Every dialogue must have a unique ID.
- Every dialogue must support all configured languages.
- Every dialogue must be compatible with offline playback.
