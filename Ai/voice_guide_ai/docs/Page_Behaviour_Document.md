# Page Behaviour Document

## 1. Overview

This document defines the behavior of Voice Guide AI for every page of the Kisan Unnati platform. It specifies when the guide should start speaking, what it should explain, when it should stop, and how it should behave in offline and online modes.

# 15. Common Behaviour

Every page should follow these rules:

- Speak only once on first visit.
- Replay only when user requests.
- Repeat automatically after 24 hours if applicable.
- Never interrupt user interaction.
- Always show subtitles while speaking.
- Display avatar during voice playback.
- Work without internet.
- Gracefully handle missing audio using subtitles.
- Maintain consistent behavior across all supported languages.
