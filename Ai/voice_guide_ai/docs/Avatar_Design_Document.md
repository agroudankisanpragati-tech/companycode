# Avatar Design Document

## 1. Overview

The Avatar represents Voice Guide AI visually while voice guidance is playing. It improves user engagement and helps farmers easily understand platform guidance through synchronized animations, expressions, and subtitles.

The Avatar does not replace Pragati AI and is only responsible for assisting users in navigating the Kisan Unnati platform.

---

# 2. Objectives

- Create a friendly digital guide.
- Improve user understanding.
- Increase farmer engagement.
- Support multilingual guidance.
- Work completely offline.
- Synchronize with voice playback.

---

# 3. Avatar Appearance

The avatar should look:

- Friendly
- Professional
- Trustworthy
- Modern
- Farmer-friendly

The avatar should not appear like a robot or game character.

---

# 4. Avatar Position

Default Position

Bottom Right Corner

Alternative Positions

- Bottom Left
- Floating
- Full Screen (Future)

---

# 5. Avatar Behaviour

Before Speaking

- Fade In
- Smile

While Speaking

- Lip Movement
- Eye Blink
- Hand Gestures
- Natural Head Movement

After Speaking

- Return to Idle State

---

# 6. Avatar Expressions

Supported Expressions

- Smile
- Neutral
- Happy
- Thinking
- Warning
- Success
- Error

Expressions should automatically change according to the dialogue type.

---

# 7. Avatar Animations

Supported Animations

- Wave
- Point
- Nod
- Idle
- Listening
- Speaking
- Loading

Future

- Walking
- Celebration
- Farming Gestures

---

# 8. Lip Synchronization

During voice playback

↓

Move lips naturally

↓

Stop immediately after audio ends

Future versions may support phoneme-based lip sync.

---

# 9. User Controls

Users should be able to

- Hide Avatar
- Show Avatar
- Change Avatar Size
- Mute Voice
- Replay Guide

---

# 10. Offline Behaviour

Without internet

- Avatar works normally.
- Animations work.
- Voice synchronization works.
- No cloud dependency.

---

# 11. Performance Requirements

- Fast loading.
- Low memory usage.
- Smooth animations.
- Minimum CPU usage.
- No UI lag.

---

# 12. Accessibility

Support

- Subtitles
- Voice
- High Contrast Mode
- Large Display Mode

---

# 13. Future Enhancements

Future versions may include

---

# 14. Design Principles

- Simple
- Friendly
- Lightweight
- Offline First
- Reusable
- Modular
- Scalable
