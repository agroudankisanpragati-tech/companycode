# AgroudAn Kisan Pragati website overview

## What this website does

AgroudAn Kisan Pragati is a farmer-focused website that brings public agricultural information pages together with online tools for farmers. In short, farmers can use it to find guidance pages, request crop recommendations, submit crop photos for a disease scan, upload soil reports, and access signed-in farming tools. Some features require an account, and live or location-based results depend on service availability. This guide explains the website's pages and workflows; it does not provide live values or independently verify an agricultural recommendation.

## Public pages and signed-in tools

Public pages include the home page, About, AI Assistant information, Crop Advisory, Crop Recommendation, Disease Detection, Mandi Prices, Farmer Stories, Contact, and account access. Feature availability or data freshness can depend on sign-in and service configuration.

Signed-in farmer pages include a dashboard, crop and advisory links, disease scanning, soil reports, a fertilizer calculator, weather and market tools, a marketplace, KVK lookup, learning content, profile, settings, notifications, and rewards. The names and destinations can be found in the site's navigation and dashboard sidebar.

To use personal dashboard features, sign in or create an account. For help locating a feature, open the navigation menu or ask the Pragati AI chat widget. The widget has a response-language selector. Its current page context is limited; it should not be described as knowing every account detail or performing actions for the user.

## Limits of this guide

This guide describes site navigation and workflows, not agricultural recommendations. Current weather, mandi prices, nearby KVKs, marketplace inventory, and account-specific records are dynamic and are not stored here. Government scheme details are intentionally outside this knowledge set. If a page shows no results or a service/configuration error, the result is not evidence that no data or service exists generally.
